## Главное правило этапа (секретность)

Репозиторий публичный, а игроки могут читать сетевые ответы в браузере. Поэтому:
- **Поля «заметки ГМ»** у статей, снов и предметов **никогда не отдаются игрокам**: ни в JSON, ни в HTML. DTO для игрока отдельно от DTO ГМ. Тесты на сериализацию, как с ответом загадки.
- **Скрытые статьи** (`HIDDEN`) игроку не отдаются вовсе, даже в списке. У засекреченных (`REDACTED`) отдаются только заголовок, категория и тизер, текст нет.
- В форме сна у поля «Название дела» подсказка ГМу: «Только внутриигровое название. Не называйте произведение, на котором основан сон.»

## Часть А. «Мир» (энциклопедия)

**Бэкенд:**
- **`WorldArticle`:**
  - `slug` (уникальный);
  - `category` (`ORG` / `PLACE` / `PHENOMENON` / `LAW` / `LEGEND` / `HISTORY` / `PERSON` / `OTHER`);
  - `title`, `teaser`, `body` (Markdown);
  - `status` (`HIDDEN` / `REDACTED` / `OPEN`);
  - `gmNotes`;
  - `revealedAt`, `updatedAt`, `updatedBy`.
- **Сидирование** из `world-seed.json` один раз, если таблица пуста.
- **API игрока:** `GET /api/world` (список `REDACTED` и `OPEN`), `GET /api/world/{slug}` (для `REDACTED` без `body`, для `HIDDEN` 404).
- **API ГМ:** полный CRUD, смена статуса (при переходе в `OPEN` ставится `revealedAt`).
- Тесты на H2 на все три статуса и на отсутствие `gmNotes` у игрока.

**Фронтенд** (`/world`, пункт навбара «Мир», при нехватке места в меню «Ещё»):
- **Оглавление-картотека** по категориям: ящики с ярлыками («Организации», «Места», «Явления», «Законы», «Легенды», «История», «Лица», «Прочее») и поиск.
  - Карточки `OPEN` обычные.
  - **`REDACTED`:** заголовок, тизер, вместо текста чёрные полосы-цензура (CSS, разной длины) и штамп «ЗАСЕКРЕЧЕНО». Подпись: «Документ откроется по ходу дела.»
- **Страница статьи:**
  - Markdown рендерить **безопасно**: никакого сырого HTML. Возьми проверенную библиотеку с отключённым HTML или санитайзером, перечисли её в отчёте;
  - таблицы и списки поддержать;
  - вики-ссылки `[[slug|текст]]` и `[[slug]]` ведут на статьи. Ссылка на `HIDDEN` или несуществующую статью рендерится как зачёркнутый текст «нет в архиве», без ссылки;
  - плашка «Открыто {дата}» для недавно открытых (7 дней). В Приёмной блок «Новое в архиве» с последними открытыми статьями.
- **ГМ:** раздел «Архив» в панели:
  - список со статусами и фильтрами;
  - редактор: поля, Markdown-текст с предпросмотром «как увидит игрок», заметки ГМ;
  - быстрые кнопки «Открыть игрокам» / «Засекретить» / «Скрыть».

## Часть Б. «Сны» (дела)

**Бэкенд:**
- **`DreamCase`:**
  - `number` (номер дела, уникальный, выдаётся по порядку), `title` (внутриигровой), `summary` (что известно сотрудникам);
  - `status` (`ANNOUNCED` / `OPEN` / `CLEARED` / `DISTORTED`; на экране «Заявлено» / «Открыто» / «Зачищено» / «Искажено»);
  - `campaign`, `rewardSummary` (текст для игроков), `gmNotes`;
  - `createdAt`, `openedAt`, `closedAt`.
- **`DreamParticipation`:** `dream`, `character`, `immersionStage` (0–4), `stageNote` (что изменилось, видно игроку), `dreamForm` (ключ расы из справочника, в том числе `closed`; null = своя форма), `joinedAt`, `leftAt`.
- **API игрока:**
  - `GET /api/dreams`: дела кампаний, где есть персонаж игрока, без `gmNotes`;
  - `GET /api/dreams/{id}`;
  - своё участие: стадия, заметка, форма.
- **API ГМ:** CRUD дел, участники, смена стадии и формы, закрытие с итогом (`CLEARED` / `DISTORTED`).
- **Вещи из сна:**
  - кнопка ГМ «Выдать трофей» в деле создаёт посылку в Сундучок (используй сервис этапа 7) с `origin` = «Из сна: Дело №{n}»;
  - у `InventoryItem` новое поле `disassembleInto` (JSON аспектов, задаёт ГМ, игроку **не показывается** до разбора);
  - игрок нажимает «Разобрать на аспекты»: предмет удаляется (количество −1), аспекты уходят в сумку. Если `disassembleInto` пусто, кнопки нет.
  - Тесты на H2.

**Фронтенд** (`/dreams`, пункт «Сны», ночная тема):
- **Список дел** как папки «Дело №0012» (PT Mono): название, статус штампом, участники (свои персонажи выделены), награда.
- **Страница дела:**
  - описание;
  - **трекер погружения** для своих персонажей: 5 делений 0–4 с подписью стадии из статьи «Погружение»;
  - заметка ГМ о стадии;
  - форма во сне, если задана: «Во сне вы — {раса}».
- **В листе персонажа:**
  - в шапке, если персонаж сейчас в открытом сне: «Во сне: Дело №… · стадия 2» и значок формы;
  - в описи Сундучка кнопка «Разобрать на аспекты» с подтверждением (что именно получится, игрок узнаёт только после разбора: «Сундучок пережёвывает предмет…» и опись полученного).
- **ГМ, раздел «Сны»:**
  - создание и редактирование дела;
  - добавление участников;
  - на каждом участнике `−`/`+` стадии и выбор формы (все расы справочника с пометкой статуса);
  - «Выдать трофей» (форма как в Сундучке, плюс поле «Разбирается на» с аспектами);
  - «Закрыть дело» с итогом.
