## Цель

## 1. Компонент шапки страницы

`src/components/ui/PageHeader.jsx`: заголовок, необязательный подзаголовок, необязательная кнопка «← Назад», место для кнопок справа.

- Подключить на всех страницах: Приёмная, Личные дела, Кампании, Кампания, Объявления, Мой пропуск, Панель ГМа, Исследования, Крафт.

- Убрать дубли: имя пользователя и «Выйти» в шапке страницы «Личные дела» и подобных. Они уже есть в навбаре.

## 2. Проходная (`/login`)

- По центру `Dossier` с ярлыком «Пропуск», внутри `Field` и `Button` из UI-кита. Логотип над формой.
- Тексты из `copy.md`, раздел «Проходная» и «Восстановление».
- Ошибка входа показывается **текстом у формы** (`Field` с ошибкой), а не только цветом.
- `SteamBackground` на фоне.
- При успешном входе вести туда, куда человек шёл до входа (если его перекинуло с защищённой страницы), иначе в Приёмную.

## 3. Приёмная (`/`)

### Гость
- Крупный `Logo variant="full"`, публичный текст из `copy.md`, кнопка «Предъявить пропуск».
- `SteamBackground`.

### Сотрудник
- `PageHeader` «Приёмная» с приветствием по имени.
- **Личные дела:** карточки своих персонажей (имя, класс и раса по-русски, уровень) со ссылкой на лист.
  - Если персонажей нет, `EmptyState` и кнопка «Завести личное дело». Она ведёт на `/characters` и сразу открывает форму создания: добавь, например, `?new=1`.
- **Быстрые действия:**
  - «Завести личное дело»;
  - «Мой лист»: если персонаж один, сразу его лист; если несколько, `/characters`;
  - «Исследования»: если персонаж один и он заклинатель, сразу его исследования; иначе выбор персонажа в маленьком диалоге со списком.
  - **Кнопок «Сундучок», «Сны», «Календарь» пока не делать,** ссылок в никуда быть не должно.
- **Свежие объявления:** последние три (`/api/announcements` уже есть, сортировка по дате на фронтенде, если бэкенд не сортирует), ссылка «Вся доска →».
- `Hint` с котом для новичка без персонажей.
- ГМ дополнительно видит кнопку «Панель ГМа».

## 4. Шапка сайта

Пункты по `copy.md`: Приёмная, Личные дела, Кампании, Объявления, Панель ГМа (только ГМ). Гость видит «Предъявить пропуск», сотрудник видит имя (подсказка «Мой пропуск») и «Сдать пропуск».

## 5. Первичная настройка ГМа

Сейчас `/admin?setup=1` показывает панель «Стать владельцем» всегда.

- Добавь публичный `GET /api/auth/setup-status` → `{ "ownerExists": boolean }`. Он ничего не раскрывает, кроме этого флага.
- Панель показывается только если `ownerExists === false`. Иначе это обычный 403.
- В `SecurityConfig` эндпоинт должен быть `permitAll` (он под `/api/auth/**`, проверь).
- Тест на H2: до назначения ГМа `false`, после `true`.

## 6. Все тексты по `copy.md`

- Пройди по `LangContext` и перепиши строки по тону и словарю `copy.md`. Строки, которых в `copy.md` нет, пиши по его правилам из раздела 1.
- Особенно:
  - убрать «Мир», «Хранилище искателей», «Хроники», «Войти в мир», «Начать путешествие» и прочий фэнтези-пафос старого сайта;
  - пропуск и допуск не путать;
  - заглавная буква только у первого слова.
- **Тексты листа персонажа, исследований и крафта:** только термины по словарю и регистр. Тон и структуру не трогать, эти экраны будут переделаны.
- Дефолтные тексты бэкенда, которые видит пользователь (сообщения исключений в ответах: `ResearchException`, ошибки авторизации), перевести на русский.

## 7. Русский словарь D&D

- `src/constants/dnd-ru.js` по разделу 4 `copy.md`: классы, расы, характеристики (кратко и полностью), навыки с характеристикой, мировоззрения.
- Функции вида `className(key)` и `raceName(key)`. Для неизвестного ключа, например самописного класса, возвращать сам ключ.
- **В базе значения не менять, хранятся английские ключи.**
- Применить везде, где класс, раса или характеристики показываются: список персонажей, Приёмная, кампании, лист (только подписи и значения в выпадающих списках: `option value` английский, текст русский), панель ГМа.
- **Названия заклинаний:**
  - фронтенд везде через `spellName`;
  - бэкенд в ответах исследования (`ResearchAttemptResponse` и подобные) отдаёт и `nameRu`, а фронтенд показывает его.
