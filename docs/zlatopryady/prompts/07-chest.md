## Цель

**Сундучок** — мимик-кладовщик Санни, хранилище наград и предметов персонажа. ГМ кладёт в него награды: аспекты, монеты, предметы, по желанию с загадкой. Игрок открывает их с анимацией, и содержимое расходится по сумке, кошельку и списку предметов. На неверный ответ загадки Сундучок кусается.

## 1. Бэкенд

**Сущности:**
- **`ChestReward`:**
  - `id`, `character`, `title`, `gmNote` (записка ГМ, видна игроку при открытии);
  - `contents` (JSON):
    - `aspects`: ключ → количество;
    - `coins`: `cp`/`sp`/`ep`/`gp`/`pp`;
    - `items`: список `{name, description, rarity, origin}`;
  - `status` (`SEALED` / `OPENED`);
  - загадка: `riddleQuestion`, `riddleAnswerHash` (ответ нормализуется: нижний регистр, без пробелов по краям, `ё` → `е`, затем хеш); `penalty` (`NONE` / `HP_1` / `LOCK_10_MIN`); `lockedUntil`; `wrongAttempts`;
  - `createdAt`, `openedAt`, `createdBy`.
  - **Ответ загадки никогда не отдаётся клиенту, даже ГМу после сохранения.**
- **`InventoryItem`:** `id`, `character`, `name`, `description`, `rarity` (`COMMON` / `UNCOMMON` / `RARE` / `VERY_RARE` / `LEGENDARY` / `ARTIFACT`), `origin` (строка, например «Награда: …», «Из сна»), `quantity`, `notes` (заметки игрока), `createdAt`.
- **`ItemTemplate`** (библиотека ГМ): `name`, `description`, `rarity`, `tags`. Хранится только в базе, **в репозиторий не сидировать**: шаблоны вводит ГМ сам, там могут быть спойлеры.

**API игрока** (владелец персонажа):
- `GET /api/characters/{id}/chest`: запечатанные и открытые награды, без ответа загадки. Для запечатанных содержимое **не отдаётся**, только `title`, наличие загадки, `lockedUntil`.
- `POST /api/characters/{id}/chest/{rewardId}/open` с телом `{answer?}`:
  - если загадки нет или ответ верен: содержимое переносится атомарно (аспекты в `aspects`, монеты в поля монет, предметы в `InventoryItem`), статус становится `OPENED`, в ответе содержимое;
  - если ответ неверен: `wrongAttempts++`, штраф (`HP_1` снижает `hpCurrent` на 1, не ниже 0; `LOCK_10_MIN` ставит `lockedUntil`), ответ `409` с `{bitten: true, penalty, lockedUntil}`;
  - пока `lockedUntil` в будущем, ответ `423`.
- `GET /api/characters/{id}/inventory`, `PATCH …/inventory/{itemId}` (только `notes` и `quantity` вниз, то есть игрок может израсходовать предмет), `DELETE …/inventory/{itemId}` (выбросить, с подтверждением на фронтенде).

**API ГМ:**
- `POST /api/admin/chest`: получатели (список `characterId` или `campaignId`, тогда всем одобренным персонажам кампании), `title`, `gmNote`, `contents`, загадка, штраф. Создаёт по награде на каждого получателя.
- `GET /api/admin/chest?status=`: все награды с получателями.
- `DELETE /api/admin/chest/{id}`: только запечатанные.
- CRUD `/api/admin/item-templates`.
- ГМ может добавить предмет напрямую в инвентарь персонажа и изменить или удалить любой предмет.

**Тесты на H2:**
- открытие переносит всё и только один раз (повторный `open` возвращает `409` «уже открыт»);
- неверный ответ кусает и применяет каждый тип штрафа;
- блокировка;
- ответ загадки не попадает ни в один JSON-ответ (проверить сериализацию);
- чужой персонаж запрещён;
- выдача на кампанию раздаёт всем одобренным;
- нормализация ответа (`Ёлка ` = `елка`).

## 2. Фронтенд

**Страница «Сундучок»** (`/chest`, пункт навбара «Сундучок» после «Личных дел», значок мимика):
- Выбор персонажа сверху, если их несколько. Можно открыть сразу по ссылке `/characters/:id/chest`.
- **Слева большой `MimicMascot`:**
  - в покое крышка чуть дышит, глаза моргают;
  - число запечатанных наград бейджем на табличке.
- **Справа «Входящие»:** запечатанные награды карточками-посылками (сургучная печать, `title`, значок загадки). Кнопка «Открыть».
  - **Без загадки:** анимация открытия (крышка откидывается, из сундука вылетают карточки содержимого), затем окно «Получено» со списком и запиской ГМ. Кнопка «Забрать в дело».
  - **С загадкой:** окно с вопросом и полем ответа. Неверно: Сундучок «кусает» (крышка хлопает, тряска, красное «Ай!» паром), текст штрафа («Сундучок откусил 1 хит» / «Сундучок обиделся на 10 минут»). При блокировке таймер до разблокировки.
- **Ниже вкладки:**
  - **«Предметы»:** таблица-опись, PT Mono для номера, редкость цветной меткой. В строке название, редкость, количество, происхождение, по клику описание и заметки игрока. Действия: «Израсходовать 1», «Выбросить».
  - **«Архив наград»:** открытые награды, когда и что пришло.
- `EmptyState`: «Сундучок пуст. Секретарша проверит позже.»
- Все анимации отключаются при `prefers-reduced-motion`: открытие становится мгновенным, укус — коротким текстом без тряски.

**Лист персонажа:**
- вкладка «Снаряжение»: блок «Предметы из Сундучка» (компактный список со ссылкой «Открыть Сундучок»);
- в шапке листа значок мимика с числом запечатанных наград, если они есть.

**Приёмная:** быстрое действие «Сундучок» с бейджем запечатанных.

**Панель ГМ, раздел «Сундучок»:**
- **Форма награды:**
  - получатели: персонажи (мультивыбор) или кампания;
  - название, записка;
  - конструктор содержимого:
    - аспекты: значки и количество;
    - монеты;
    - предметы: из библиотеки шаблонов или вручную;
  - загадка (вопрос, ответ, штраф).
  - Предпросмотр «так увидит игрок».
- **Список отправленных** с фильтром: запечатано или открыто, получатель, неверные попытки.
- **Библиотека предметов** (CRUD).
