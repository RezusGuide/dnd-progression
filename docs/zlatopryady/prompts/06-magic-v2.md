## Ответы на вопросы этапа 5b

1. **Карточка «Другое» (своя раса):** сделать её обычной записью справочника с ключом `CUSTOM` и статусом по умолчанию `undecided`. Тогда игрок её не видит, пока ГМ не включит в «Справочнике». То же для «Своей предыстории»: ключ `CUSTOM` в `backgrounds.json`, по умолчанию `allowed`.
2. **Источники:** коды везде. У классов: `PH14`, `TCE` (Tasha's Cauldron of Everything), `VSS` (Valda's Spire of Secrets), `SGEH` (Steinhardt's Guide to the Eldritch Hunt), `CR` (Critical Role), `DMG` (Dungeon Masters Guild), `UA`, `LL` (laserllama), `HB` (homebrew). Полное название книги показывать во всплывающей подсказке (`title`). Таблицу «код → название» держать в одном месте (`data/sources.json`).
3. **Классы «Только для НИП»:** ГМ может заводить персонажей с такими классами, игрок нет. Сервер проверяет по роли.
4. Новая колонка `spellcasting_ability`, размер строкой, лимит 4, пересчёт хитов на несколько уровней: всё одобрено.

     - граф связный;
